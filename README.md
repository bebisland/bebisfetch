# 🍼 bebisfetch

A lightweight, colorful, and fast system information tool written in Go.

bebisfetch is licensed under the [MIT license](./LICENSE).

## 🚀 Features

* Bebis ASCII Art!
* Shows up username, hostname, kernel, uptime etc.
* Package indicator currently supports `pacman` and `flatpak`.
* Colored usage and disk bars.

## 📦 Requirements

* Written for Linux
* Written in Go 1.27.1

## 🛠️ Building

Just run `./build.sh`, you should get an executable `bebisfetch` file.
